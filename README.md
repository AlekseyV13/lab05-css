# Практична робота: Основи CSS

Цей проєкт є багатосторінковим HTML-сайтом, стилізованим за допомогою CSS. Робота виконана для закріплення навичок роботи з каскадними таблицями стилів, блоковою моделлю, Flexbox та адаптивним дизайном.

## Що було зроблено
- Створено дизайн-систему на базі CSS-змінних (`:root`).
- Реалізовано спільний дизайн для трьох сторінок (`index.html`, `about.html`, `contact.html`).
- Використано Flexbox для створення горизонтального меню навігації та двоколонкового макета на сторінці "Про мене".
- Стилізовано текстовий контент, списки, таблицю, HTML-форму та мультимедійні елементи (аудіо/відео).
- Забезпечено повну адаптивність інтерфейсу для мобільних пристроїв за допомогою Media Queries (`responsive.css`).

## Як запустити проєкт
1. Склонуйте репозиторій на свій комп'ютер.
2. Відкрийте папку проєкту в редакторі коду (наприклад, VS Code).
3. Відкрийте файл `index.html` у будь-якому сучасному браузері.
4. *Рекомендація:* Для кращого досвіду розробки використовуйте розширення Live Server у VS Code.
