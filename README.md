# Практична робота: Додавання JavaScript до HTML/CSS-сайту

Цей проєкт є багатосторінковим сайтом, який було "оживлено" за допомогою клієнтського JavaScript згідно з вимогами до практичної роботи.

## Що було реалізовано (JavaScript):
1. **Динамічна навігація:** Автоматичне підсвічування активного пункту меню.
2. **Мобільне меню:** Кнопка-бургер для відкриття/закриття меню на смартфонах.
3. **Темна тема:** Перемикач світлої/темної теми зі збереженням вибору користувача у `localStorage`.
4. **Кнопка "Вгору":** З'являється при прокручуванні та плавно повертає на початок сторінки. Динамічний рік у футері.
5. **Акордеон:** Плавне розгортання/згортання блоків з інформацією (FAQ/Навички).
6. **Фільтрація:** Кнопки для сортування контенту за категоріями без перезавантаження сторінки.
7. **Форма зворотного зв'язку:** - Клієнтська валідація введених даних.
   - Лічильник символів для `textarea`.
   - Збереження чернетки тексту в `localStorage` (захист від втрати даних при оновленні сторінки).
   - Перехоплення `submit`, збір даних через `FormData` та виведення повідомлення про успіх.
8. **Модальне вікно:** Вікно, що спливає поверх контенту, з можливістю закриття по кліку на хрестик, темний фон (overlay) або клавішу `Esc`.

## Технічні деталі
- Усі скрипти винесені в окремий файл `main.js` та підключені через атрибут `defer`.
- Відсутні inline-обробники подій (усі слухачі додані через `addEventListener`).
- Реалізовано перевірку наявності DOM-елементів перед виконанням логіки, що дозволяє використовувати один JS-файл на різних сторінках без помилок у консолі.
